# Privacy Policy for HTML Code Editor

**Application:** HTML Code Editor (`com.prahladinala.htmlcodeeditor`)  
**Developer:** Prahlad Inala  
**Effective Date:** November 1, 2026  
**Last Updated:** November 2026

HTML Code Editor ("the Application") is an offline-first mobile code editor and web playground engineered by Prahlad Inala. This Privacy Policy outlines how the Application handles user information, file permissions, and device storage.

---

## 1. Core Philosophy: 100% Local-First & Private

We believe your source code, design mockups, and programming experiments belong exclusively to you. HTML Code Editor operates without user accounts, remote databases, or backend telemetry servers. Everything you type, format, and preview remains stored in your device's isolated local storage.

---

## 2. Information We Do Not Collect

HTML Code Editor does not collect, record, or transmit any Personally Identifiable Information (PII). Specifically:

- **No User Accounts:** No sign-up, registration, usernames, passwords, or emails required.
- **No Source Code Tracking:** Your HTML, CSS, JavaScript, text files, and starter templates are never uploaded to our servers or any third-party cloud.
- **No Location Data:** We do not request or track GPS, Wi-Fi, or cellular network location.
- **No Media or Biometric Access:** We do not access your camera, microphone, photos, media libraries, or contacts.
- **No Financial Data:** No payment cards, banking credentials, or financial accounts are collected or stored.

---

## 3. File Access & Storage Handling

HTML Code Editor adheres to modern Android security and scoped storage standards:

- **Native Storage Access Framework (SAF):** When opening or saving code files (`.html`, `.htm`, `.css`, `.js`, `.txt`), the app utilizes Android's official system file picker (`ACTION_OPEN_DOCUMENT` and `ACTION_CREATE_DOCUMENT`). The app can only access the specific file or directory you explicitly pick. It has no access to your broader personal files.
- **Editor Preferences (Android SharedPreferences):** The application saves non-sensitive interface preferences on your device's private storage, including:
  - Font size zoom level (`A-` / `A+` stepping and pinch-to-zoom preferences).
  - Word wrap toggle state (soft wrap vs. horizontal scrolling).
  - Syntax highlighting theme settings.
  - In-app review prompt spacing counter.
- **Bundled Starter Templates:** Pre-packaged templates (such as HTML5 Boilerplate, Flexbox Pricing Card, CSS Grid Gallery, Todo List, Modal Popup, Tailwind CSS, Bootstrap 5, Dark Mode Toggle, and React 18 CDN) are stored locally within the application package and run offline.

You can completely remove all locally saved preferences and cached data at any time by clearing the application storage in Android Settings or by uninstalling the application.

---

## 4. Device Permissions

The Application requests only the minimal hardware and operating system capabilities necessary to provide code editing features:

- **`android.permission.ACCESS_NETWORK_STATE`:** Used exclusively to verify whether an active internet connection is present when you load templates that rely on external CDNs (e.g., React 18, Bootstrap 5, Tailwind CSS). If you are offline, the app displays a non-blocking CDN warning indicator. No user data, device identifiers, or IP addresses are logged or sent during this check.
- **No Broad Storage Permission:** The app does not require legacy `READ_EXTERNAL_STORAGE` or `MANAGE_EXTERNAL_STORAGE` permissions on modern Android versions (Android 11+ through Android 16 / API 36).

---

## 5. Third-Party Libraries & External Links

### Google Play In-App Review

The Application integrates the official Google Play Core Review library (`com.google.android.play:review`) to let users voluntarily rate the app without leaving the editor interface. This interaction is handled directly by Google Play Services and is governed by [Google's Privacy Policy](https://policies.google.com/privacy).

### External CDN Resources (User-Initiated)

When you write or preview code containing external web libraries (e.g., `<script src="https://unpkg.com/react...">` or Tailwind CDN), the built-in Android WebView loads those public scripts directly from the respective public CDN provider over HTTPS, exactly like a desktop web browser. HTML Code Editor does not inject any tracking or proxy scripts into your code previews.

### Developer Links

The app includes optional shortcuts to "Contact Developer" (`prahladinala.in`) and "More Apps by Prahlad Inala" (`pub:Prahlad Inala`). Tapping these links opens your device's default browser or the Google Play Store app.
