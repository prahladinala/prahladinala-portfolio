# React Hooks Deep Dive

React Hooks completely revolutionized how we write components. Let's look closely at `useEffect` and `useMemo`.

## The `useEffect` Hook

The most common mistake with `useEffect` is omitting dependencies or recreating them constantly on every render.

<Callout type="info" title="Why Dependency Arrays Matter">
Every reactive value (state, props, or variables derived from them) used inside `useEffect` must be listed in its dependencies array to prevent stale closure bugs.
</Callout>

```jsx
import { useEffect, useState } from "react";

export function UserProfile({ userId }) {
  const [user, setUser] = useState(null);

  useEffect(() => {
    // Only runs when userId changes!
    fetch(`/api/users/${userId}`)
      .then((res) => res.json())
      .then((data) => setUser(data));
  }, [userId]);

  if (!user) return <div>Loading...</div>;
  return <div>{user.name}</div>;
}
```

<Callout type="warning" title="Warning: Infinite Re-render Loop">
Never update state unconditionally inside `useEffect` if that state variable is also in the dependency array, otherwise your component will continuously trigger re-renders indefinitely!
</Callout>

## Performance with `useMemo`

If you have a very expensive calculation, you can wrap it in `useMemo` to ensure it only recalculates when its specific dependencies change.

```jsx
const expensiveResult = useMemo(() => {
  return computeExtremelyHeavyTask(data);
}, [data]);
```

<Callout type="success" title="Rule of Thumb">
Use `useEffect` for synchronization with external systems (APIs, DOM, localStorage). For calculating derived state from props or existing state, compute it directly during rendering instead!
</Callout>
